所以正确的做法是：判断和切分不能交给模型
判断“要不要切”必须是图外的前置逻辑，基于 token 数硬算，不经过模型。 流程应该是：

抓取后先算 token 数（用 tokenizer，不调模型）。

和图外设定的阈值比（比如模型上下文 128K，留出输出空间，阈值设 80K）。

没超：整篇投喂给模型，让它自己决定内部怎么处理。

超了：先按规则切，再投喂。切分动作在图外完成，模型根本不参与这个决策。

也就是说，LangGraph 里那个条件边，判断依据应该是 token 数，不是让模型去“读一遍然后决定”。模型只在“已经切好的块”上做提取，不负责切分决策。
